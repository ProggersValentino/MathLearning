| Identity                     | Meaning                                         |
| ---------------------------- | ----------------------------------------------- |
| $\vec{a} \cdot \vec{b} = 0$  | The vectors are **perpendicular** to each other |
| $\vec{0} \cdot \vec{b} = 0$  | The vectors are **orthogonal**                  |
| $\vec{a} \times \vec{b} = 0$ | The vectors are **parallel**                    |


| Property                                                             | Identity                                                                         | Example |
| -------------------------------------------------------------------- | -------------------------------------------------------------------------------- | ------- |
| Communicative Property <br>of Addition                               | $\vec{a} + \vec{b} = \vec{b} + \vec{a}$                                          |         |
| Associative Property of addition                                     | $(\vec{a} + \vec{b}) + \vec{c} = \vec{a} + (\vec{b} + \vec{c})$                  |         |
| Associative Property of <br>scalar multiplication                    | $s(t\vec{a}) = (st)\vec{a}$                                                      |         |
| Communicative Property of <br>Dot Product                            | $\vec{a} \cdot \vec{b} = \vec{b} \cdot \vec{a}$                                  |         |
| Associative Property of Scalar<br>Multiplication with Dot Product    | $k(\vec{a} \cdot \vec{b}) = (k\vec{a}) \cdot \vec{b} = \vec{a} \cdot (k\vec{b})$ |         |
| Associative Property of Scalar <br>Multiplication with Cross Product | $k(\vec{a} \times \vec{b}) = (k\vec{a}) \times (k\vec{b})$                       |         |



| Identity                                                                               | Meaning                                                                                                                                       |
| -------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| $\vec{a} - \vec{b} = \vec{a} + (-\vec{b})$                                             | definition of vector subtraction                                                                                                              |
| $k(\vec{a} + \vec{b}) = k\vec{a} + k\vec{b}$                                           | Scalar multiplication distributes over vector addition                                                                                        |
| $\|k\vec{a}\| = \vert k \vert \; \|\vec{a}\|$                                          | Multiplying a vector by a scalar, scales the magnitude by that scalar value                                                                   |
| $\|\vec{a}\| \ge 0$                                                                    | The magnitude of a vector is always non-negative                                                                                              |
| $\|\vec{a}^2\| + \|\vec{b}^2\| = \|\vec{a} + \vec{b}\|^2$                              | Pythagorean theorem can be applied to vector addition                                                                                         |
| $\|\vec{a}\| + \|\vec{b}\| \ge \|\vec{a} + \vec{b}\|$                                  | Cauchy-Schwarz inequality states that for a valid triangle, a hypotenuse will be **less than or equal to** its adjacent and opposite vectors. |
| $\|\vec{a}\| = \sqrt{\vec{a} \cdot \vec{a}}$                                           | A vector's magnitude can be discovered by apply the dot product to itself                                                                     |
| $\vec{a} \cdot (\vec{b} + \vec{c}) = \vec{a} \cdot \vec{b} + \vec{a} \cdot \vec{c}$    | The dot product will distribute over vector addition and subtraction                                                                          |
| $\vec{a} \times \vec{b} = (-\vec{a}) \times (-\vec{b})$                                | The vector result of a cross product is the same if negated                                                                                   |
| $\vec{a} \times \vec{b} = -(\vec{b} \times \vec{a})$                                   | The cross product is anti-communicative indicating that **order matters**                                                                     |
| $\vec{a} \times (\vec{b} + \vec{c}) = \vec{a} \times \vec{b} + \vec{a} \times \vec{c}$ | The cross product distributes over vector addition and subtraction                                                                            |
