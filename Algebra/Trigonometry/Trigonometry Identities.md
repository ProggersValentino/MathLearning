 
## Symmetry

####  Sine & Cosine identities
Each side relate to each other. So if we take a vector and mirrored it across each $x$ and $y$ axis' we will get its symmetrical vector 
![[Pasted image 20260611125147.png]]

which when taking each vector we can see they all equal the same thus the idea that they have **symmetry** no matter the quadrant

#### Tangent 
The same can be done for tangent, we know that $tan\theta = {sin\theta \over cos\theta}$ and if we take the mirrored vector of tangent which is $tan(180 + \theta)$ which is the same as $tan\theta$ as:

$tan(180 + \theta) = {sin(180 + \theta) \over cos(180 + \theta)}$

we do **minus $180$** we are left with:

$tan\theta = {sin\theta \over cos\theta}$
