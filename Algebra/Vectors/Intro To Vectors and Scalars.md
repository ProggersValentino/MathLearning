##### what is a vector?
A vector is a set of numbers that have two definitive factors, which is a **magnitude** and a **direction**. Vectors are used to describe a set of displacements to a particular point. Each Vector have a **tail** which defines the **origin point** and a **head** which defines the **terminal point**.

## Zero Vector
[game math chp 2](https://gamemath.com/book/vectors.html)

A zero vector is a vector where all values are a boldface $0$:

$0 = \begin{bmatrix} 0 \\ 0 \\ 0 \end{bmatrix}$

However, while it might seem so, the zero vector is not a point but rather should be treated as way to express "no displacement"
