If the vector components are unknown but you have the **magnitude** and **direction** then using **unit circle** equations you will be able to figure out the exact components 
![[Pasted image 20260610142948.png]]

given the problem we know that we have a **magnitude** of $5$ and a **direction** of $60^{\circ}$ so to find the $x$ we need to use $cos\theta$ as per the unit circle because we know that on the $x$-axis, $cos$ is used. So following with **unit circles** then, to find our $y$ we need to use $sin\theta$.

$\begin{aligned} cos\theta = {x \over hyp} \;\;\;\;\; \\[1em] x = hyp \cdot cos\theta \;\;\;\;\; \\[1em] x = 5 \cdot cos60^{\circ}\;\;\;\;\; \\[1em] x = 2.5 \;\;\;\;\; \end{aligned}$ $\begin{aligned} sin\theta = {y \over hyp} \\[1em] y = hyp \cdot sin\theta \\[1em] y = 5 \cdot sin60^{\circ} \\[1em] y = 4.3\end{aligned}$


Which means the **terminal point** of the vector is $\vec{t} = (2.5, 4.3)$ giving us our vector components
