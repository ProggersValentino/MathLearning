##### What is a Scalar multiplier?
A scalar multiplier is a single number that when applied to a **vector** will amplify that result by the scalar number.

Take the component vector $A$:

$\overrightarrow{A} = (2, 3)$

and the scalar:
$scalar = 2$

to apply it we just need to multiply each component of $\overrightarrow{A}$ by the scalar:

$2\overrightarrow{A} = 2 \cdot (2, 3)$
$2\overrightarrow{A} = (4, 6)$

So now what happens if we do a **negative**?  

$-2\overrightarrow{A} = (-2) \cdot (2, 3)$
$-2\overrightarrow{A} = (-4, -6)$

The result just simply flips and scales the vector by 2.
