When adding/subtracting vectors, the follow the same principle as normal addition where its each component of a vector **added on to each other**

$\vec{a} + \vec{b} = (\vec{a}x + \vec{b}x,\; \vec{a}y + \vec{b}y)$

its also the same if we want to **subtract** vectors then:

$\vec{a} - \vec{b} = (\vec{a}x - \vec{b}x,\; \vec{a}y - \vec{b}y)$

##### Adding Algebraically & graphically
[khan acad vid](https://www.khanacademy.org/math/algebra-home/alg-vectors/alg-vector-addition-subtraction/v/adding-vectors)

Representing it visually, we can see that for the addition and subtraction, the **second vector** begins at the **terminal point** of the first vector its adding/subtracting to. Which then the final vector is established at the **terminal point of the second vector **.

The order does not necessarily matter as long as the **magnitude and direction** are **not changed**. 

In doing so, it naturally fulfills the **parallelogram rule**: when vectors are added and subtracted on the same origin it creates a parallelogram.

For subtracting, we're actually subtracting by $-b$ instead of $b$ which flips the $\vec{b}$ by 180 degrees allowing us to find the result vector of $\vec{a} - \vec{b}$
