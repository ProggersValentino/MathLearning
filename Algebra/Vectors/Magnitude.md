##### What is Magnitude?
The magnitude of a vector is the distance from an **initial point** to a **terminal point** all compiled to **one number**

This is boiled into whats essentially the **Pythagoras theorem** where:

$||\vec{m}|| = \sqrt{\Delta x^2 + \Delta y^2}$

we can see that it forms a right angled triangle which $a$ and $b$ are the components of $\overrightarrow{AB}$ which are $\Delta x$ and $\Delta y$. 

So if we want to find $c$ we need to order the Pythagoras Theorem to:
$\begin{aligned} c^2 = a^2 + b^2 \\[1em] c = \sqrt{a^2 + b^2} \end{aligned}$
