Documentation of my personal math journey where I go through math topics and document based on how I understand the topic

This is best viewed using [Obsidian](https://obsidian.md/) 

### Instructions 

1. Clone repository onto your local machine 
2. Open Obsidian
3. Press "Open folder as vault" and locate the cloned repository

## External Libraries

The external libraries below are used heavily within the knowledge base and are required to be installed from obsidian to get the best viewing experience:

- [Excalidraw](https://community.obsidian.md/plugins/obsidian-excalidraw-plugin)
- [Obsidian Desmos 3D](https://github.com/Eroxl/obsidian-desmos-three-d)
